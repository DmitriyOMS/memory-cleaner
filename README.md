Memory Cleaner — настольное приложение на C# и WPF для просмотра пользовательских программ и освобождения занимаемой ими оперативной памяти. Оно объединяет одноимённые процессы, показывает их потребление памяти и позволяет выгрузить выбранные приложения после подтверждения.

Программа работает только по явной команде пользователя: автоматической фоновой выгрузки приложений нет.

**[Открыть полную иллюстрированную инструкцию пользователя (PDF)](MemoryCleaner-UserGuide.pdf)**

## Основные возможности

- Отображение общего объёма оперативной памяти, занятого и свободного места.
- Группировка одноимённых процессов в одну строку с указанием их количества.
- Расчёт суммарной памяти каждой группы по показателю `WorkingSet64`.
- Поиск по имени программы, описанию и названию компании.
- Сортировка программ по убыванию потребления памяти.
- Множественный выбор приложений с помощью флажков.
- Быстрый выбор программ, у которых есть видимое окно.
- Предварительная оценка памяти выбранных приложений.
- Обязательное подтверждение перед завершением процессов.
- Итоговый отчёт об успешно, частично или не завершённых программах.
- Защита ряда системных процессов, антивируса, терминалов, агентов и самого Memory Cleaner.

> Memory Cleaner не обещает ускорить компьютер. Освобождение памяти может помочь при её нехватке, но завершение нужных программ способно прервать работу и привести к потере несохранённых данных.

## Требования

- Windows 10 или Windows 11 x64.
- Для установки готовым установщиком или запуска автономного `MemoryCleaner.exe` среда .NET не требуется.
- Для запуска framework-dependent сборки — **.NET 10 Desktop Runtime**.
- Для самостоятельной сборки проекта — **.NET 10 SDK**.

Проверить установленные среды выполнения можно командой:

```bash
dotnet --list-runtimes
```

В выводе должна быть строка `Microsoft.WindowsDesktop.App` с версией `10.x`.

## Установка на компьютер

Запустите `MemoryCleaner-Setup-2.0.0.exe` и следуйте страницам мастера:

1. Выберите вариант установки — для текущего пользователя или для всех пользователей, если этот выбор предложен Windows.
2. На странице **«Выбор папки установки»** укажите каталог вручную или нажмите **«Обзор»**.
3. На странице **«Выбор папки в меню “Пуск”»** задайте расположение ярлыков. Можно отключить их создание соответствующим флажком.
4. На странице **«Расположение значков»** отметьте **«Создать значок на рабочем столе»**, если нужен отдельный ярлык.
5. Проверьте выбранные параметры и нажмите **«Установить»**.
6. После завершения можно сразу запустить Memory Cleaner.

Установщик размещает в выбранном каталоге автономный `MemoryCleaner.exe` и PDF-инструкцию. Ярлык инструкции также добавляется в меню «Пуск». Удалить приложение и его ярлыки можно через список установленных приложений Windows.

## Запуск приложения

1. Откройте папку с приложением или используйте созданный установщиком ярлык.
2. Дважды щёлкните `MemoryCleaner.exe`.
3. Если Windows показывает предупреждение безопасности, запускайте файл только при доверии к его источнику.
4. После открытия главного окна нажмите **«Обновить список»**, если список программ ещё не загружен.

Для выполнения отдельных действий Windows может запросить права администратора. Не запускайте программу с повышенными правами без необходимости.

## Сборка и запуск из исходного кода

Выполните команды из корня репозитория:

```bash
dotnet restore native/MemoryCleaner.csproj
dotnet build native/MemoryCleaner.csproj --configuration Debug --no-restore
dotnet run --project native/MemoryCleaner.csproj
```

Актуальная версия проекта находится в каталоге `native` и использует WPF.

## Сборка установщика

Дополнительно требуется **Inno Setup 7**. Компилятор находится автоматически в `PATH`, в стандартном каталоге установки или в локальном каталоге `installer/.tools/inno`. Также можно задать полный путь к `ISCC.exe` в переменной среды `ISCC`.

Из корня проекта выполните:

```bash
powershell -ExecutionPolicy Bypass -File installer/build-installer.ps1
```

Скрипт заново публикует автономный `MemoryCleaner.exe` в корень и создаёт установщик. Если приложение уже опубликовано, используйте:

```bash
powershell -ExecutionPolicy Bypass -File installer/build-installer.ps1 -SkipAppBuild
```

Результат сохраняется как `installer/output/MemoryCleaner-Setup-2.0.0.exe`. Сценарий установки находится в `installer/MemoryCleaner.iss`.

## Главное окно

В верхней части окна отображаются сведения об оперативной памяти. Ниже расположены поле поиска, кнопки управления и таблица программ.

Доступные действия:

- **Обновить список (`F5`)** — заново получить процессы и показания памяти.
- **Выбрать оконные** — отметить доступные приложения с главным окном.
- **Снять выбор** — очистить все установленные флажки.
- **Выгрузить выбранные** — открыть подтверждение и завершить выбранные программы.

В таблице представлены:

- название программы;
- количество объединённых процессов;
- суммарное потребление памяти;
- назначение или описание;
- автор или компания.

Одна строка может соответствовать нескольким процессам. Например, у браузера часто одновременно работают процессы окна, вкладок, расширений и графического ускорения. Memory Cleaner показывает их вместе и рассчитывает общую сумму.

## Как найти нужную программу

1. Обновите список.
2. Просмотрите программы с наибольшим потреблением памяти — сортировка выполняется по убыванию.
3. При необходимости введите в поиск имя, описание или компанию.
4. Используйте **«Выбрать оконные»**, если хотите отметить только приложения с видимыми окнами.
5. Проверьте и при необходимости измените выбор вручную.

Поиск не заменяет данные новыми процессами: для актуального состояния системы снова нажмите **«Обновить список»**.

## Как выгрузить приложения

1. Сохраните документы и завершите важные операции в программах, которые собираетесь закрыть.
2. Отметьте только те приложения, назначение которых вам понятно.
3. Проверьте список и приблизительный объём памяти выбранных программ.
4. Нажмите **«Выгрузить выбранные»**.
5. Внимательно прочитайте перечень программ в диалоге подтверждения.
6. Нажмите **«Да»**, чтобы продолжить, либо **«Нет»** или `Escape`, чтобы отменить операцию.

В диалоге отображаются до 12 названий. Если выбрано больше программ, остальные обозначаются как **«и ещё N»**. По умолчанию выбран ответ **«Нет»**.

После завершения операции приложение показывает отчёт и обновляет список процессов.

## Как выполняется выгрузка

Для каждого выбранного процесса Memory Cleaner:

1. Пытается закрыть главное окно через `CloseMainWindow()`, если окно существует.
2. Если главного окна нет, сразу использует `Kill()`.
3. Ожидает завершения процесса до 2 секунд.
4. Принудительно завершает процессы, которые остались запущенными.
5. После принудительного завершения ждёт ещё до 500 мс.
6. Повторно получает список процессов и обновляет окно.

Итог может иметь один из следующих статусов:

- **Успешно** — все процессы выбранной группы завершены.
- **Частично** — завершена только часть процессов группы.
- **Не найдена** — программа уже завершилась или исчезла из списка.
- **Ошибка** — завершить процесс не удалось, например из-за ограничений доступа.

Оценка освобождённой памяти всегда приблизительна. Windows может перераспределять память, а другие приложения способны одновременно запускать и завершать процессы. Поэтому расчётное и фактическое изменение показаний могут отличаться.

## Безопасность

Memory Cleaner применяет два уровня защиты: отключает флажки для защищённых записей в интерфейсе и повторно фильтрует имена процессов в сервисе выгрузки.

В список защищённых входят критические процессы Windows, антивирус, терминалы, агенты и собственный процесс приложения. Это снижает риск случайного завершения важных компонентов, но не заменяет внимательную проверку выбранных программ.

Перед выгрузкой:

- сохраните все несохранённые файлы;
- не закрывайте незнакомые процессы;
- проверьте, не выполняет ли программа загрузку, установку, синхронизацию или другую важную операцию;
- не проверяйте работу Memory Cleaner на приложениях с важными данными.

Приложению не требуется передача списка процессов по сети.

## Типичные проблемы и решения

### При запуске появляется сообщение об отсутствии .NET

Установите **.NET 10 Desktop Runtime**, а не только базовый .NET Runtime. Затем снова откройте `MemoryCleaner.exe`.

Проверка:

```bash
dotnet --list-runtimes
```

Нужна среда `Microsoft.WindowsDesktop.App 10.x`.

### Список пустой или у программы нет описания и автора

Нажмите **«Обновить список»**. Некоторые сведения могут быть недоступны из-за прав Windows, особенностей самого процесса или его завершения во время сканирования. Отсутствие метаданных не обязательно означает неисправность.

### Повторный запуск открывает другой экземпляр или ведёт себя неожиданно

Закройте лишние экземпляры через обычное окно приложения и снова обновите список. Не пытайтесь завершить собственный процесс Memory Cleaner: он входит в защищённый список.

### Не все процессы выбранной программы завершились

Программа может автоматически перезапускать свои компоненты, а Windows — запрещать доступ к отдельным процессам. Обновите список и проверьте итоговый статус. Если процесс нужен системе или другой программе, не завершайте его повторно без понимания последствий.

### Оценка освобождённой памяти не совпала с фактической

Это ожидаемо: расчёт основан на моментальном снимке `WorkingSet64`, а состояние памяти постоянно меняется. Оценку нельзя считать точным измерением результата.

## Краткая памятка

1. Сохраните важные данные.
2. Нажмите **«Обновить список»** или `F5`.
3. Найдите понятные вам пользовательские приложения.
4. Отметьте их флажками.
5. Проверьте ориентировочный объём памяти.
6. Нажмите **«Выгрузить выбранные»** и подтвердите действие.
7. Изучите отчёт и обновлённый список.
